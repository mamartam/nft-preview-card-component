# NFT preview card component

This project was created based on a Frontend Mentor [https://www.frontendmentor.io/] challenge. The layout and design idea come from Frontend Mentor, while the code implementation is my own.

## 📦 Technologies
- HTML5 – semantic structure for content
- CSS3 – styling, flexbox layout, hover effects, responsive design
- Google Fonts – Outfit font for typography
- HSL Colors – consistent and modern color scheme

## 📚 What I Learned
- Implementing hover overlay effects with smooth transitions
- Using Flexbox for layout and spacing
- Working with custom fonts and HSL color schemes
- Structuring semantic HTML for better accessibility and readability

## 🚀 How It Can Be Improved?
Enhance interactivity, e.g., clickable buttons or links to NFT details
